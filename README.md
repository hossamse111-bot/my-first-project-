# مواعيدي — نسخة تطوير إشعارات الآيفون

تطبيق ويب PWA لإدارة مواعيد المدير والتذكيرات على الآيفون.

## الحالة
هذا مستودع تطوير، وليس تطبيقًا منشورًا. رابط Google Apps Script الحالي لم يتغير.

## المكونات
- واجهة عربية متجاوبة وقابلة للتثبيت على الشاشة الرئيسية.
- خدمة Node.js لقراءة المواعيد من Google Sheets.
- خدمة Web Push لتسجيل أجهزة المستخدم والمدير وإرسال التنبيهات.
- صلاحية المسؤول لإدارة توقيت التنبيهات.

## الإعداد
1. شغّل `npm install`.
2. انسخ `.env.example` إلى `.env` وأضف القيم السرية محليًا أو في إعدادات الاستضافة فقط.
3. فعّل Google Sheets API وأنشئ حساب خدمة بصلاحية قراءة فقط، ثم شارك الجدول معه.
4. أنشئ مفاتيح VAPID بالأمر `npx web-push generate-vapid-keys`.
5. شغّل `npm start` على استضافة HTTPS بخادم مستمر وتخزين دائم.
6. على iPhone بنظام iOS 16.4+، افتح التطبيق من Safari ثم «إضافة إلى الشاشة الرئيسية» ووافق على الإشعارات.

**تحذير:** المستودع عام حاليًا. لا ترفع إليه كلمات مرور أو مفاتيح خاصة أو ملف .env أو بيانات المواعيد.
**ملاحظة:** الأوقات مثل «بعد المغرب» تحتاج ساعة دقيقة لإرسال إشعار في موعد مضبوط.
